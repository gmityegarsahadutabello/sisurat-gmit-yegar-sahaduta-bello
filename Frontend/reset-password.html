Reset Password Memerlukan Verifikasi Tatausaha

Untuk keamanan akun Anda, proses reset password tidak dapat dilakukan secara online. Silakan datang ke kantor gereja dan temui Staf Tata Usaha dengan membawa identitas diri (KTP/KK).

Langkah-langkah Reset Password:
  1. Datang ke Kantor Gereja
    Kunjungi kantor GMIT YEGAR pada jam kerja
  2. Temui Staf Tata Usaha
    Sampaikan bahwa Anda lupa password akun jemaat
  3. Verifikasi Identitas
    Tunjukkan KTP/KK untuk verifikasi identitas Anda
  4. Admin akan Reset Password
    Admin akan membuat password sementara untuk Anda
  5. Login & Ganti Password
    Login dengan password sementara lalu segera ganti password Anda
Jam Pelayanan Tata Usaha:
Senin - Jumat: 08.00 - 15.00 WITA
Sabtu: 08.00 - 12.00 WITA
Kembali ke Halaman Login
